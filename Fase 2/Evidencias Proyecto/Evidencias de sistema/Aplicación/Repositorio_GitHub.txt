DESCRIPCIÓN
  Aplicación web que automatiza la conciliación de las ventas con tarjeta del hotel,
  en pesos (CLP) y dólares (USD): cruza los abonos de Transbank con el BORDERO del
  ERP CM SFM, las cuentas por cobrar de Amex, Diners, Visa y Mastercard, y la cartola
  bancaria (BancoEstado y Banco de Chile). Deja solo las excepciones por revisar, con
  una acción sugerida, y guarda cada conciliación en un historial con reportes Excel/PDF.

VERSIÓN DOCUMENTADA
  Conciliación bancaria v3.14.0 (noviembre de 2026). El número aparece en el pie de
  página de la aplicación y en config/settings.py (APP_VERSION).

TECNOLOGÍA
  Python 3.12+ · Django 5.1+ (plantillas HTML, CSS y JavaScript) · SQLite (piloto,
  compatible con PostgreSQL vía DATABASE_URL) · pandas, openpyxl, xlrd, lxml, odfpy ·
  reportlab (PDF) · httpx (dólar observado) · whitenoise.

PUESTA EN MARCHA (resumen)
  cd Conciliacion_Bancaria_2.0
  python -m venv entorno
  entorno\Scripts\activate            (macOS/Linux: source entorno/bin/activate)
  pip install -r requirements.txt
  python manage.py migrate
  python manage.py createsuperuser
  python manage.py runserver          → http://127.0.0.1:8000/

PRUEBAS AUTOMÁTICAS
  python manage.py test apps.conciliacion apps.usuarios     (212 pruebas con datos sintéticos)
